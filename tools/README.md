# Vetted tools

The tool stack for the MILLZ Marketing OS. A tool earns "vetted" when Soren has used it in real work and trusts the output. Everything else is evaluating or watching.

## Vetted

- Claude Code — core agent and build tool. Repo workflows, autosave hooks, verbatim brief capture. In daily use.
- Beamery Brain — org's live plugin repo: 4 plugins, 32 skills (Marketing 19, CSM 6, Brand 4, Sales 3). Live and adopted.
- Jarvis (Hatch) — intake, triage, prioritization across projects. Muse -> Clarvis -> projects model (2026-10-09).
- GitHub — project source of truth. Process and decisions live here.

## Evaluating

- MoltSets — unlimited B2B contact data at $27/mo, API-only, live Nov 1. Verify quality and coverage once live before trusting it in a GTM stack. See [resources/2026-10-09-moltsets-launch-intel.md](../resources/2026-10-09-moltsets-launch-intel.md).
- Composio — managed tool and MCP layer for AI agents: 1,500+ app integrations with managed OAuth, one MCP endpoint that gives Claude Code and other agents authenticated access to Gmail, Slack, GitHub, Drive, and more. Free tier, Pro $29/mo. Candidate infrastructure for Clarvis as orchestrator/librarian. Evaluating 2026-10-09.
- Granola — bot-free AI meeting notepad. Captures system audio (no bot joins the call), merges typed notes with the transcript into structured summaries. Free Basic (30-day history), Business $14/user/mo, Enterprise $35. Note: notes live on Granola servers. Evaluating 2026-10-09.
- Blender — free, open-source 3D creation suite (modeling, animation, rendering, video editing). GPL, free for commercial use. Candidate for 3D and motion work behind branded video projects. See [resources/2026-10-09-blender.md](../resources/2026-10-09-blender.md). Evaluating 2026-10-09.

## Watching

- Apollo / ZoomInfo — incumbent contact data, seat-based pricing. Pricing model under pressure from API-only entrants.
